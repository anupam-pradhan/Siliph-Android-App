# Siliph Privacy Policy

**Effective Date**: August 16, 2026

Siliph ("we", "our", or "the app") is designed from the ground up as a **local-first, privacy-respecting productivity application** for Android.

---

## 1. Core Privacy Principles

1. **No Account Required**: You do not need to register, log in, or provide any personal information to use Siliph.
2. **Local On-Device Processing**: All core PDF operations (merging, splitting, compressing, annotating, signing, watermarking, redacting), image operations, document scanning, OCR (Optical Character Recognition), NLP text summaries, and file utilities run **entirely on your device**.
3. **No Background File Uploads**: Siliph does not transmit your documents, images, signatures, passwords, or extracted text to remote servers or cloud storage.
4. **Android Storage Access Framework (SAF)**: Siliph accesses only the specific files or folders you explicitly choose through Android's system file picker or system Photo Picker.

---

## 2. Permissions & Data Safety

- **Camera**: Used exclusively when you choose to scan physical documents or capture photos via the camera. Captured images are processed on-device and saved only where you direct.
- **Storage / Files**: Accessed strictly via standard Android Storage Access Framework (SAF). Siliph does not request broad all-files storage access.
- **Analytics & Telemetry**: Siliph does not log, track, or transmit document content, OCR text, or passwords.
