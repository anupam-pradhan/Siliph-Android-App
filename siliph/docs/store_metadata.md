## 3. Full Description (up to 4000 characters)
Siliph is a private, ultra-fast, local-first document productivity suite for Android.

No account needed. No mandatory cloud. Your files are processed securely on your device.

### 📄 All-In-One PDF Suite
- **PDF Reader**: Fast rendering with page jump, pinch-to-zoom, and smooth navigation.
- **Merge & Split**: Combine multiple PDFs or split by custom ranges and page counts.
- **Page Organizer**: Extract, delete, reorder, reverse, and rotate pages with ease.
- **PDF Compressor**: Reduce file sizes with clear savings comparisons and quality presets.
- **Annotation & Redaction**: Draw, highlight, stamp, add text, or permanently redact sensitive data.
- **Electronic Signatures**: Draw or import your signature and place it onto documents.
- **Watermark & Page Numbers**: Add diagonal/header/footer watermarks and custom page numbers.
- **Password Protection**: Encrypt PDFs with user/owner passwords or unlock protected files.
- **Metadata Editor**: View, edit, or strip PDF metadata properties.
- **PDF Text-to-Speech (TTS)**: Listen to document text read aloud with custom playback speeds.

### 🖼️ Image Tools & Converter
- **Image Compression**: High-efficiency compression with exact target KB/MB precision.
- **Resize & Crop**: Aspect-ratio locked resizing, custom cropping, and rotation.
- **Format Conversion**: Convert between JPG, PNG, and WebP instantly.
- **Remove EXIF**: Strip camera metadata and GPS tags before sharing.
- **Passport / ID Photo Maker**: Standard 4×6 photo sheets with 35×45mm cut guides.
- **Images <-> PDF**: Convert multiple images to a single PDF or extract PDF pages to images.

### 📷 Document Scanner & Offline OCR
- **Camera Document Scanner**: Multi-page capture with automatic perspective correction and enhancement filters.
- **On-Device OCR**: Optical Character Recognition for Latin and Devanagari (Hindi) text.
- **Searchable PDF**: Rebuild scanned documents with an invisible, selectable OCR text layer.
- **QR & Barcode**: Live QR code generator and instant barcode reader.

### 🤖 On-Device AI Tools (100% Offline)
- **AI Summarizer**: Instant executive summaries, key takeaways, and entity detection (dates, emails, phone numbers, links).
- **AI Document Chat**: Ask questions about document text with instant page citations.

### 📁 File Utilities & Archive
- **Storage Access Framework (SAF)**: Full integration with Android's system file picker and Photo Picker.
- **ZIP Utilities**: Create and extract ZIP archives safely.
- **Storage Analyzer & Duplicate Finder**: Identify large files and duplicate content to reclaim storage.

### 🔒 Private by Design
- No sign-in or account creation.
- 100% offline core processing.
- No background file uploads or hidden telemetry.
